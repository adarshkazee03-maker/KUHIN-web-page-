
## 💡 For Future Development

### Adding New Pages
1. Copy hero section from existing page
2. Use `glass-panel` class for cards
3. Apply `hover-lift` class to interactive elements
4. Use `fade-in-up` animation for entrance
5. Follow spacing pattern (`py-5`, `p-4`, `g-4`)

### Creating New Components
1. Use glass-morphism effect
2. Add fade-in-up animation
3. Apply hover-lift on interaction
4. Use primary color (#2c3e91)
5. Follow 24px border radius pattern

### Updating Styles
Edit CSS variables in base template:
```css
--primary-color: #2c3e91
--secondary-color: #00897b
--accent-color: #7e57c2
```
