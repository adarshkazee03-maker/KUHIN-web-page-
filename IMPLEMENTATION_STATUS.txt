================================================================================
  FEATURE SPECIFICATIONS
================================================================================

FORM VALIDATION:
  - Name: 2-100 characters, letters/spaces/hyphens/apostrophes only
  - Email: Valid RFC 5322 format, max 254 characters
  - Subject: 3-200 characters
  - Message: 10-5000 characters, spam detection enabled
  
SPAM DETECTION:
  - Blocks: viagra, cialis, phentermine, casino, poker, lottery
  - Blocks: "click here", "buy now", "free money", "work from home"
  - Case-insensitive matching
  
RATE LIMITING:
  - Limit: 5 messages per IP per hour
  - Window: 3600 seconds
  - Storage: Django cache (no database overhead)
  - Automatic reset after 1 hour
  
EMAIL SENDING:
  - To: kuhin@ku.edu.np (configurable)
  - From: noreply@kuhin.ku.edu.np (configurable)
  - Reply-To: user's email address
  - Includes: timestamp, client IP, formatted body
  - Confirmation email sent to user
  
ERROR HANDLING:
  - Form validation errors shown to user
  - Rate limit errors shown gracefully
  - Email failures logged + user-friendly message
  - All errors logged to logs/kuhin.log

SECURITY:
  - CSRF token protection on form
  - Input validation on all fields
  - Spam keyword detection
  - Email format validation
  - Rate limiting (DoS prevention)
  - Environment-based credentials
  - No credentials in code

================================================================================
  INSTALLATION & DEPLOYMENT
================================================================================

DEVELOPMENT SETUP (5 steps):
  1. Copy .env.example to .env
  2. Set DEBUG=True in .env (uses console backend)
  3. Create logs directory: mkdir -p logs
  4. Run verification: python verify_email_config.py
  5. Start server: python manage.py runserver
  6. Visit: http://localhost:8000/contact/

PRODUCTION SETUP:
  1. Copy .env.example to .env
  2. Set DEBUG=False
  3. Add SMTP credentials to .env
  4. Create logs/ directory with write permissions
  5. Run verification: python verify_email_config.py
  6. Test form submission
  7. Monitor logs/kuhin.log

SMTP PROVIDERS SUPPORTED:
  - Gmail (default in .env.example)
  - Office 365
  - Custom SMTP servers
  - Any provider using TLS/SMTP
